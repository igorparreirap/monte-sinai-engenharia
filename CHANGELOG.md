## [1.0.0] - 2026-10-23

First public release, live at [montesinaiengenharia.com.br](https://montesinaiengenharia.com.br).

### Added

- Single-page corporate website: hero, about, services, contact and map sections
- WhatsApp contacts with a pre-filled greeting message
- Contact form sending e-mails through authenticated SMTP, with server-side validation, honeypot and rate limiting
- SEO: meta tags, Open Graph, schema.org structured data, sitemap and Google Search Console verification
- Accessibility features: semantic HTML, labelled fields, skip link and reduced-motion support
- Optimized WebP images and self-hosted fonts
- Security headers, forced HTTPS with HSTS and protection of deploy control files
- CI (format, lint, type check, tests, build) and automatic deploy over FTPS with GitHub Actions
- README in English and Portuguese
